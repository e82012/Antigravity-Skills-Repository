## 3. 品質檢查清單 (Quality Checklist)

### 3.1 邏輯與邊界
- [ ] 所有可能為 `null` 或 `undefined` 的變數皆有防禦性檢查
- [ ] 陣列/集合操作時，空陣列 `[]` 不會導致崩潰或邏輯異常
- [ ] 所有數值計算與判斷正確處理了 `0` 或空字串 `""` 的邊界情況
- [ ] 在多執行緒或並發環境下，臨界資源有正確的鎖機制或事務隔離

### 3.2 效能與資源
- [ ] 迴圈中無資料庫查詢 (N+1)、API 請求或耗時的 I/O 操作
- [ ] 所有外部連線與資源（如 DB Connection, File Stream）均在使用後正確關閉或釋放
- [ ] 大量資料查詢時，有正確使用分頁或 `chunk` 串流處理
- [ ] SQL 查詢有正確使用 Index，無 Full Table Scan

### 3.3 安全性
- [ ] 所有 SQL 語句均使用參數綁定，絕無字串拼接
- [ ] 敏感資訊（如 Password, Token）無 `console.log` 殘留，且在 Response 中被隱藏
- [ ] 跨網站請求防禦（CSRF）與輸出轉義（XSS）已妥善處理
- [ ] 涉及權限的操作，已嚴格實作 Authorization 檢查，非僅依靠 Authentication

### 3.4 後端特定 (以 PHP/Laravel 為例)
- [ ] 業務邏輯已抽離至 Service 層，Controller 保持輕量與職責單一
- [ ] 佇列任務 (Queue Job) 具備冪等性 (Idempotence) 設計，重複執行不產生副作用
- [ ] 配置讀取僅使用 `config()`，避免在代碼中直接調用 `env()`
