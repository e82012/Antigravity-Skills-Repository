# 台灣用語對照表（技術／專有名詞）

> 供 Agent 用字查核：**一律使用台灣用語欄的寫法**，禁止使用大陸用語欄的寫法。
> 用字不確定時查本表；表上沒有的詞，以台灣出版的技術書籍、教育部術語為準。

## 最容易踩雷的陷阱（同字不同義）

| 詞 | 台灣的意思 | 大陸的意思 | 正確用法 |
|---|---|---|---|
| 文件 | document（文書） | file（檔案） | file 一律寫「檔案」；document 寫「文件」 |
| 程序 | procedure（步驟） | program（程式） | program 寫「程式」；process 寫「行程」（大陸：进程） |
| 行／列 | 行＝直的（column）、列＝橫的（row） | 行＝橫的（row）、列＝直的（column） | 表格用「橫列直行」；不確定就寫 row／column |
| 質量 | mass（物理量） | quality（品質） | quality 一律寫「品質」 |
| 對象 | 交往對象（人） | object（物件） | object 一律寫「物件」 |
