# 產物格式

落地位置依計畫書 §1.3，本檔只補「欄位怎麼填」。根目錄為
`C:\Users\user\Documents\整併\doc`。

## 1. 頁面文件 `doc/{站台代號}/{頁面名稱}.md`

四個部分依序為功能盤點、操作步驟、測試結果、觀察項。

### 新增：文件開頭的環境指紋

每份頁面文件開頭加一行環境指紋，供下次重放與跨站沿用判斷：

```md
環境指紋：前綴 `custom-modal-`（Notification 為 `ant-`）｜React 18 ＋ antd v5 cssinjs｜
viewport {w}×{h}｜盤點自 {網址}
```

前綴不同就代表**不能沿用另一站的選擇器**，這行是給下一個 session 的警示。

### §2 操作步驟：改為「自然語言 ＋ 定位錨點」

Re-test（計畫書 §7.4）與原站重放都要重跑同一串操作，純自然語言等於每次重新探索。
每個步驟補一欄定位錨點：

```md
| # | 操作 | 定位錨點 | 預期結果 |
|---|---|---|---|
| 1 | 玩家帳號填入 `smoke0908a` | `#memId` | 欄位顯示輸入值 |
| 2 | WM 百家樂限紅選「100 / 10k」 | `#data_WM_Baccarat` 所屬 `[class*=select-selector]` | 選中項顯示 `100 / 10k` |
| 3 | 按提交 | `button[type=submit]`（文字為「提 交」） | 送出 API 並跳轉 |
```

錨點優先序：**語意 `id`** > `type`／`name` > 去空白後的文字 > AX ref（ref 每次都會變，僅供當次使用）。

`rc_select_N`、`rc-tabs-N` 這類自動編號 id 跨渲染會變，**不算語意 id**，不可寫進操作步驟。

## 2. 總檢查清單 `doc/{站台代號}/{站台代號}總檢查清單.md`

格式依計畫書 §1.3.1，不重述。補兩條填寫規則：

- 以 JS 降級操作完成的項目，判定填 `⚠️`，說明欄寫「以 JS 降級操作，UI 層未驗證」。
- 統計數字實際數過，且用兩種數法交叉驗證；第一次就剛好吻合時換個範圍定義再數一次。

## 3. 證據檔 `doc/e2e/{站台}/{頁面代號}/`

| 檔名 | 內容 |
|---|---|
| `{情境}_{站別}_api.json` | `read_network_requests` 的 request／response 落檔 |
| `{情境}_{站別}_ui.png` | 截圖，依 `browser-recipes.md` §6 的四種時機 |
| `{情境}_before_{站別}.json` / `_after_` | DB 快照（計畫書 §5.5） |
| `{頁面代號}_console.md` | console error 級別訊息，無則寫「無 error 級別訊息」 |

`{站別}` 用 `origin`（原站）／`merge`（合併站）。

## 4. 問題紀錄 `doc/畫面測試問題.md`

格式依計畫書 §7.2／§7.3，不重述。AI 撰寫時必附：站台代號與頁面網址、可直接照做的重現步驟
（帶定位錨點）、原站與合併站結果並列、證據檔路徑。
