# 交棒 (Handoff)

`handoff` 是**分岔**，`/compact` 是**接續**。當你要一個**全新的 session**、但需要**保留現在這段對話**時，用這個；只是想在同一段對話裡讓前面的輪次被摘要掉，用 `/compact`。

## 步驟

1. **寫交棒文件**。落點在暫存區的 `tmp/handoff/`，**不進專案目錄**——它是過程產物，不是交付物。檔名帶日期與主題（`2026-08-03-結算流程.md`）。

2. **不要重抄已經存在的產物**。規格、ADR、`CONTEXT.md`、工單已經寫下來的東西，用**路徑引用**，不要複製進來。交棒文件只寫「這些檔案裡沒有的東西」——也就是對話裡的判斷與尚未落地的結論。

3. **格式**：

   ```markdown
   # 交棒：<主題>

   ## 目標
   我們在做什麼，為什麼。

   ## 已經決定的
   - 決策 + 理由，一條一行

   ## 還沒決定的
   - ⚠️ 待決事項，以及它卡住了什麼

   ## 已存在的產物
   - `docs/adr/0007-結算時序.md`
   - `tmp/settle/tickets/03-退款.md`

   ## 下一步
   接手的人第一件事該做什麼。

   ## 建議使用的技能
   - `implement`（工單 #03 已經 ready）
   ```

4. **敏感資料要遮**。API key、密碼、token、真實個資一律不寫進去。

5. **回報路徑**。把完整路徑印給使用者，方便他開新 session 時引用。

## 完成判準

接手的 agent 只讀這份文件加上它引用到的檔案，就能講出「現在卡在哪、下一步做什麼」——不需要回頭看原本的對話。

## 使用者參數

使用者在指令後面附的說明，當成**這次交棒的聚焦方向**：只圍繞那個方向整理，不要把整段對話全部倒出來。
