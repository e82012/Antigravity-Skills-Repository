## 2. 功能目的

免費旋轉卡是一種活動贈品，由後台管理員發放給指定會員。  
會員在前台活動頁兌換後，可在指定遊戲中享有免費旋轉次數，不消耗會員點數餘額。  
此功能主要用於新會員促活動與留存活動，發放與兌換動作均需記錄至操作紀錄。

## 4. 主要流程

1. 後台管理員進入免費旋轉卡管理頁。
2. 選擇目標會員與旋轉次數，送出發放請求。
3. 系統驗證管理員權限與會員是否存在。
4. 系統建立 `free_spin_cards` 紀錄，狀態設為 `pending`。
5. 系統寫入操作紀錄（發放者、受贈者、次數、時間）。
6. 會員登入前台，在活動頁看到可兌換的免費旋轉卡。
7. 會員點擊兌換，系統驗證卡片狀態（`pending`）。
8. 卡片狀態更新為 `used`，寫入使用紀錄。
9. 會員進入遊戲時帶入免費旋轉參數，由遊戲商處理免費旋轉邏輯。

## 7. 特殊規則

| 編號 | 規則 | 說明 | 影響範圍 |
|---|---|---|---|
| 1 | 每張卡只能使用一次 | 狀態由 `pending` → `used`，不可重複兌換 | 前台兌換流程 |
| 2 | 免費旋轉由遊戲商處理 | 後台只負責發卡與狀態更新，實際免費旋轉邏輯在遊戲商端 | 遊戲登入參數 |
| 3 | 客戶 B（天界）卡片有效期限不同 | 天界預設 7 天，911 預設 30 天，詳見 `project_diff.md` | DB 欄位 / 過期邏輯 |

## 10. 測試重點

### 正常流程
- [ ] 管理員可發放免費旋轉卡給指定會員。
- [ ] 發放後 DB 紀錄正確（status = pending）。
- [ ] 發放後有寫入操作紀錄。
- [ ] 會員前台可看到待兌換的卡片。
- [ ] 會員兌換後狀態更新為 used。
- [ ] 會員進入遊戲時正確帶入免費旋轉次數。

### 權限測試
- [ ] Admin 可發放、查詢。
- [ ] 客服只能查詢，不能發放或刪除。
- [ ] 代理無法操作。
- [ ] 會員只能看自己的卡片。

### 邊界與異常測試
- [ ] 重複兌換同一張卡片應被阻擋。
- [ ] 已過期的卡片不可兌換。
- [ ] 發放給不存在的會員應報錯。
- [ ] 不同客戶有效期限差異邏輯是否正確。

## 11. 接手注意事項

1. 修改此功能前，請先確認 `project_diff.md`，天界與 911 有有效期限差異。
2. 若新增遊戲商支援，需確認遊戲商接受的免費旋轉參數格式。
3. 若修改 `free_spin_cards` 資料表，需確認各客戶是否需要同步 migration。
4. 目前天界的過期卡片失效問題尚未處理，接手時請確認是否有後續計畫。
