# 功能總覽｜免費旋轉卡

## 功能目的

後台管理員可發放「免費旋轉卡」給指定會員，會員在前台活動頁兌換後，可在指定遊戲免費轉動一定次數。  
主要用於活動推廣與新會員留存，不消耗會員點數餘額，但仍計入活動錢包紀錄。

## 所屬模組

- 系統：管理後台 / 玩家前台
- 模組：event
- 功能：免費旋轉卡（free_spin_card）

## 使用角色

| 角色 | 是否可使用 | 備註 |
|---|---|---|
| Admin | 是 | 後台發放卡片、查詢紀錄 |
| 客服 | 是 | 可查詢發放紀錄，不可刪除 |
| 代理 | 否 | 不開放代理直接發放 |
| 會員 | 是 | 前台兌換與使用 |
| 系統排程 | 待確認 | 是否有過期自動失效排程待確認 |

## 主要入口

| 入口 | 路徑 / 頁面 | 說明 |
|---|---|---|
| 後台頁面 | `/admin/event/free-spin-card` | 管理人員發放與查詢 |
| 前台頁面 | `/activity/free-spin` | 會員兌換與查看可用次數 |
| API | 待補 | 前後端分離，具體路由見 `api.md` |
| 排程 / Queue | 待確認 | 是否有過期失效排程 |

## 影響範圍

- **前台**：是，會員活動頁顯示可用免費旋轉次數，遊戲入口需帶入免費旋轉參數
- **後台**：是，管理員可發放、查詢、停用免費旋轉卡
- **API**：是，有新增發放與查詢 API
- **DB**：是，新增 `free_spin_cards` 資料表
- **Log**：是，發放與兌換動作需寫入操作紀錄
- **權限**：是，依角色區分查詢與操作權限
