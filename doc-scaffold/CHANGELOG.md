## 新增文檔清單

### 1. 新增模板（3 份）

#### `templates/api.md`
- **用途**：定義功能的所有 API 路由、Request/Response、權限、錯誤碼
- **何時需要**：涉及新增或修改 API 路由時
- **檔案大小**：~400 行（含說明）
- **包含章節**：
  - API 清單表
  - 各 API 的詳細定義（Request/Response）
  - 錯誤碼表
  - 權限與認證規則
  - 注意事項與風險標記

#### `templates/database.md`
- **用途**：定義相關資料表、欄位、索引、異動規則
- **何時需要**：涉及新增或修改資料表時
- **檔案大小**：~450 行（含說明）
- **包含章節**：
  - 相關資料表清單
  - 詳細表結構（欄位、型別、約束）
  - 索引設計
  - 資料異動規則（INSERT/UPDATE/DELETE）
  - 效能與維護建議

#### `templates/bdd.md`
- **用途**：使用 Gherkin 語言定義驗收標準與測試場景
- **何時需要**：涉及複雜流程或高風險操作時
- **檔案大小**：~350 行（含說明）
- **包含章節**：
  - Feature 描述
  - 正常流程 Scenario
  - 失敗與邊界情境 Scenario
  - 高風險情境 Scenario
  - 驗收檢查清單
  - 測試資料與環境說明

### 2. 支援文檔（2 份）

#### `GUIDE.md`（新增）
- **用途**：補充 SKILL.md 的缺口，提供各文檔的詳細填寫方法與決策樹
- **檔案大小**：~600 行
- **包含內容**：
  - 何時產出「完整版」vs「簡化版」的決策樹
  - 各文檔的詳細填寫指南（README / maintenance_notes / api / database / bdd）
  - 常見陷阱與檢查清單
  - 高風險功能必檢清單（金流、權限、遊戲邏輯、資料一致性、日誌）
  - 交叉引用檢查方法

#### `CROSS_REFERENCE.md`（新增）
- **用途**：定義六份文檔間的關鍵字段對應規則，確保文檔間一致性
- **檔案大小**：~500 行
- **包含內容**：
  - 文檔間的依賴關係圖
  - 「使用角色」「相關資料表」「API 權限」「錯誤碼」等關鍵字段的跨文檔對應
  - 專案差異的標記規則
  - 高風險功能的特別檢查清單
  - 常見不一致案例與解決方案
  - 自動化檢查建議

### 3. 核心文檔優化（SKILL.md）

#### 重點優化
1. **產出邏輯優化**
   - 新增「版本判斷」：完整版 vs 簡化版
   - 新增「產出判斷標準」清單
   - 明確簡化版的使用場景

2. **執行流程擴展**（從 5 步擴至 8 步）
   - 新增 Step 1：複雜度分析
   - 新增 Step 2：版本判斷
   - 新增 Step 6：關鍵字段一致性檢查
   - 新增 Step 7：全局差異文檔評估

3. **格式規範細化**
   - 新增「文檔特有規範」（api/database/bdd 各自的規範）
   - 強調「禁止事項」（特別是完整版的自相矛盾）

4. **品質檢核擴展**
   - 通用檢核（所有版本必檢）
   - 完整版專用檢核（api / database / bdd）
   - 完整版交叉驗證檢核（新增）
   - 簡化版特殊檢核（新增）

## 使用指南（改造後）

### 快速開始

1. **使用者描述功能** → Skill 自動判斷版本（完整 vs 簡化）
2. **Skill 產出文檔** → 根據 GUIDE.md 填寫
3. **產出前檢查** → 對照 CROSS_REFERENCE.md 驗證一致性
4. **產出說明** → Skill 告知哪些待確認、是否需同步全局文檔

### 關鍵改變

#### ✅ 新的「版本判斷」流程
```
功能明確？
├─ 不明確 → 簡化版（3 份）
└─ 明確
   ├─ 涉及 API？→ 產出 api.md
   ├─ 涉及 DB？→ 產出 database.md
   └─ 複雜流程？→ 產出 bdd.md
```

#### ✅ 新的「一致性檢查」機制
```
完整版文檔產出前 → 執行交叉檢查
  □ 角色一致性
  □ 表名一致性
  □ API 權限一致性
  □ 錯誤碼覆蓋性
  □ 流程對應性
```

#### ✅ 新的「全局差異同步」提醒
```
若功能涉及專案差異
  → 建議同步更新 `02_project_diff/`
    ├─ Example_api_route_diff.md
    ├─ Example_database_diff.md
    └─ Example_feature_enable_matrix.md
```
